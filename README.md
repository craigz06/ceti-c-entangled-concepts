# CETi-C — Concept Entanglement and Interstellar Communication

Early-stage conceptual scaffolding, not a built application yet. This
repo is an organized home for the ideas as they develop.

## Core hypothesis

Two independent, blind "reductions" — predictions committed before an
outcome resolves — correlating more than chance predicts is a signal,
**regardless of what claim is made about the mechanism behind it.**
The correlation is the finding; explaining *why* it happens is a
separate, later question.

Modeled on a double-blind experimental design, using the same
predict → commit → observe → log discipline as the existing SCO
project.

## Folders

- `object/` — who/what is doing the reducing: AETI, the human test
  subject, and AI's (undecided) role as a third object.
- `place/` — where the reduction happens: known universe, unknown
  universe, or high-dimensional/phase space.
- `time/` — when: instantaneous.
- `intent/` — the experimental protocol itself: double-blind,
  predict-commit-observe-log.
- `logistics/` — the practical open questions and decisions made so
  far (tooling, undecided roles, holding frame for what this even is).
