# Object

Who/what is doing the reducing.

- **AETI** — Advanced Extraterrestrial Intelligence. The other side of
  the entanglement.
- **The human test subject** — Craig (or whoever runs a given trial),
  producing one of the two blind reductions.
- **AI** — a third object. Role not yet decided; three candidates:
  1. Seeded-image target generator (AI produces the thing being
     blindly predicted, not a predictor itself).
  2. Parallel blind receiver, run alongside the human subject (AI
     makes its own independent reduction, compared against the
     human's).
  3. The medium/entangled link itself (AI as the channel the
     correlation runs through, not a participant on either end).

See `logistics/README.md` — this is logged there too as an open
question, since which role AI plays determines the tooling.
