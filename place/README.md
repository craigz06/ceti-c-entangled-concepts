# Place

Where the reduction happens. Three-way split:

- **Known universe** — the observable, already-mapped physical
  universe.
- **Unknown universe** — physical, but beyond current observation/
  knowledge.
- **High-dimensional / phase space** — not a location in physical
  space at all. The actual interest is here specifically:
  **possibility reduction/collapse**, not particles.
  - Phase space = every state a system could be in.
  - The event of interest is that space collapsing to one actual
    state — the reduction itself, wherever/whatever substrate it
    happens on.
